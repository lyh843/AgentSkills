# Evidence Sheet Template

## Source Map
- List each file once with a short role label.
- Prefer `source-name.pdf p.N` anchors for PDF notes.

## Per-file Notes
- `Source:` file path or short label
- `Summary:` 2-5 lines
- `Important anchors:` pages, headings, or line spans
- `Caveats:` weak extraction, missing pages, ambiguity

## Key Facts
- Record only claims that are likely to matter later.
- Keep each fact tied to a source anchor.

## Glossary
- Term
  - short definition
  - source anchor

## Timeline
- Date or version marker
  - what changed
  - source anchor

## Comparison Table
- Source
- Claim
- Evidence
- Confidence

## Open Questions
- Track contradictions, missing definitions, and follow-up items.
