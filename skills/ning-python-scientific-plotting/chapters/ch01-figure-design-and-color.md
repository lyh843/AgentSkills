# Chapter 1: 科研论文配图的绘制与配色基础

## Core Idea
科研配图不是装饰，而是实验数据与分析结论的独立表达单元。先满足期刊规范和信息准确性，再通过布局、字体与配色提高可读性。

## Frameworks Introduced
- **必要性原则**：只有当图能补充文字、直观展示结果或承担后续论证时才绘制。
  - When to use: 决定一张图是否应进入正文、补充材料或被删除时。
  - How: 写出图要回答的问题；若表格或一句文字已经足够，就不增加图；只保留关键结果，不堆叠原始数据和中间过程。
- **易读性原则**：标题、坐标、单位、图例和标注应让图脱离正文后仍能被正确理解。
  - When to use: 审查图是否存在歧义、字号过小或视觉层级混乱时。
  - How: 先检查变量与单位，再检查视觉编码，最后缩放到投稿尺寸验证可读性。
- **一致性原则**：图中数据、术语、符号、有效数字和视觉样式必须与正文及其他插图一致。
  - When to use: 多图、多人协作或论文定稿阶段。
  - How: 建立统一样式表；固定字体、字号、颜色、线宽和标记；逐项核对正文中的变量名与数值。
- **期刊优先工作流**：目标期刊的文件格式、尺寸、字体、颜色模式和分辨率决定最终输出，而不是绘图软件的默认值。

## Key Concepts
- **线性图**：由绘图程序或数据分析软件生成的折线图、散点图、柱形图等，是本书的主要对象。
- **像素图**：由像素构成，放大会失真；常见格式为 JPEG、PNG、TIFF。
- **矢量图**：由几何图元构成，与分辨率无关；常见格式为 EPS、PDF、SVG、AI。
- **RGB**：面向屏幕显示的加色模式，三个通道通常取 0–255。
- **CMYK**：面向印刷的减色模式，纸质出版可能要求使用。
- **HEX**：代码中常用的 `#RRGGBB` 颜色表示。
- **单色系 Sequential**：用亮度或饱和度的单向变化编码有序数值。
- **双色渐变 Diverging**：围绕关键中心值向两侧发散，适合正负偏差或高于/低于基准的数据。
- **多色系 Qualitative**：用不同色相区分类别，不表达大小顺序。

## Mental Models
- **Use publication size as the truth**：不要在大屏幕预览尺寸上判断字号和线宽，应按最终栏宽检查。
- **Use color to encode, not decorate**：每种颜色都应承担分组、顺序、偏差或重点提示的含义。
- **Think vector first**：线条、文本和符号为主的图优先输出矢量格式；照片、显微图等再考虑高分辨率位图。
- **One visual grammar per paper**：把整篇论文的图看成同一视觉系统，而不是互不相关的作品。

## Anti-patterns
- **展示所有中间图**：增加审稿负担，并削弱真正结论的显著性。
- **直接接受软件默认样式**：默认字号、边框、颜色和图例通常不匹配目标期刊。
- **用相近颜色区分类别**：相邻对象难以辨认，转为灰度后尤其容易失效。
- **类别颜色过多**：书中建议 ColorBrewer 类别通常控制在 5–8 个，尽量不要超过 10 个。
- **盲目提高 DPI**：文件巨大但信息量没有增加；线图应优先矢量化。
- **忽略黑白与色觉可访问性**：只靠红绿差异表达结论会使部分读者无法区分。

## Reference Tables
| 数据语义 | 首选颜色主题 | 判断规则 |
|---|---|---|
| 从低到高的连续量 | 单色系 | 亮度随数值单调变化 |
| 围绕零点、均值或目标值 | 双色渐变 | 中心使用浅色，两侧使用不同色相 |
| 无顺序类别 | 多色系 | 色相不同但视觉权重接近 |
| 处理组与对照组 | 互补色或高对比双色 | 同时配合线型或标记避免只靠颜色 |

| 输出对象 | 推荐格式 | 关键检查 |
|---|---|---|
| 线图、文字、符号 | PDF、EPS、SVG | 字体嵌入、线宽、透明度 |
| 照片、显微图 | TIFF、PNG | 分辨率、颜色模式、压缩损失 |
| 屏幕或在线补充材料 | RGB | 色彩与浏览器显示 |
| 印刷文件 | 按期刊要求使用 RGB 或 CMYK | 转换后颜色是否偏移 |

## Worked Example
要表达相对基准值的温度异常：先确定中心值为 `0`，因此选择双色渐变色系，而不是普通彩虹色；将负值映射为冷色、正值映射为暖色、零值映射为浅色；再检查色条上下限是否关于零点对称。若还需区分类别，用线型或分面，不继续叠加更多颜色语义。最后把图缩放到期刊栏宽，确认刻度、单位和色条标签仍清晰。

## Key Takeaways
1. 每张图先回答一个研究问题，再决定是否值得绘制。
2. 规范性、易读性和一致性优先于视觉新奇。
3. 线图优先矢量格式，位图按期刊要求设置合理 DPI。
4. 连续、发散和类别数据分别使用单色系、双色渐变和多色系。
5. 图应在最终出版尺寸下完成可读性检查。
6. 配色必须兼顾黑白打印和色觉差异。
