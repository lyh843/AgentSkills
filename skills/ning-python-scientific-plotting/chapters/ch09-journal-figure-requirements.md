# Appendix: 部分英文期刊投稿插图规范

## Core Idea
投稿规范是输出参数的最终来源。以下规则整理自本书 2023 年版；截至生成日期 2026-08-31，它们只能作为准备清单，正式投稿前必须核对目标期刊当前 Author Guidelines。

## Frameworks Introduced
- **期刊反向设计**：先确定目标期刊和版面尺寸，再设置画布、字体、线宽、颜色模式和文件格式。
- **最终尺寸验证**：所有字号、符号和线条要求都应在缩放后的出版尺寸检查。
- **可编辑优先**：线图和文本优先提交可编辑矢量文件，同时保留原始绘图脚本。
- **图注独立性**：图注应让读者不依赖正文也能理解变量、面板、符号和误差定义。

## Key Concepts
- **Final size**：期刊排版后的实际尺寸，而不是绘图软件中的放大预览。
- **Editable vector**：AI、EPS、PDF、PS、SVG 等可编辑矢量格式。
- **Line art**：主要由黑白线条、文字和符号组成的图。
- **Combination artwork**：线条、文字、灰度或彩色图像混合的插图。
- **Panel label**：多面板图中的 `a`、`b`、`c` 等编号。
- **Figure legend/caption**：解释整图、面板、符号、缩写、误差线和统计方法的文字。

## Mental Models
- **Journal rules override house style**：本 skill 的默认建议不能覆盖期刊明确要求。
- **Prepare once, export many**：保留矢量母版和脚本，再按期刊要求导出格式。
- **Accessibility survives conversion**：颜色图转灰度、缩小或打印后仍应保留主要信息。
- **A caption completes the figure**：图文件与图注共同构成完整科研表达。

## Anti-patterns
- **把旧版投稿规则当作当前规则**：期刊会更新格式、尺寸和提交流程。
- **最终提交前才缩放图片**：会暴露字号过小、线条过细和面板拥挤问题。
- **只交 JPEG 线图**：有损压缩会损害文字和线条。
- **红绿作为唯一对比**：不利于色觉差异读者。
- **图中放置长标题和大段说明**：正文信息应移到图注。
- **图注不解释误差线、缩写或面板**：图无法独立理解。

## Submission Checklist
1. 打开目标期刊当前指南，记录栏宽、最大高度、文件格式、颜色模式和 DPI。
2. 按最终尺寸创建 Figure，不在导出时临时缩放。
3. 统一字体、字号、线宽、符号和面板编号。
4. 检查误差线定义、样本量、单位、缩写和统计阈值。
5. 进行灰度与色觉可访问性检查。
6. 优先导出 PDF/EPS/SVG 等矢量文件；照片按要求导出 TIFF/PNG。
7. 在 100% 和最终印刷尺寸检查文字、线条和图例。
8. 单独编写能脱离正文理解的图注，并逐一描述面板。
9. 保留源代码、原始数据、字体信息和最终导出参数。

## Worked Example
目标期刊要求单栏图。先从当前指南取得栏宽和字体范围，在 Matplotlib 中直接用英寸换算设置 `figsize`；线图保存为 PDF，照片面板以规定 DPI 的 TIFF 嵌入或单独提交；将图缩放到最终尺寸检查最小文字和线宽；最后验证红绿对比是否还能通过线型、标记或亮度区分，并让图注定义所有面板、误差线和缩写。

## Key Takeaways
1. 本附录是历史参考，不是 2026 年的实时投稿规则。
2. 最终栏宽决定画布、字体和布局。
3. 线图优先矢量，照片按期刊 DPI 和颜色模式输出。
4. 可访问性、统一性和图注完整性是跨期刊通用要求。
5. 每次投稿都要重新核对目标期刊当前指南。
