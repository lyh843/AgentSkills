# Chapter 5: 多变量图形的绘制

## Core Idea
多变量图用位置、颜色、大小、方向、形状或坐标变换同时编码多个变量。每增加一个视觉通道都会增加认知负担，只保留与研究问题直接相关的维度。

## Frameworks Introduced
- **视觉通道预算**：最重要变量放在 x/y 位置；次要连续量使用颜色或大小；类别使用色相或标记。
- **坐标系匹配**：笛卡尔、三元、三维、平行坐标和径向投影分别适配不同数据约束。
- **降维后解释**：PCA、Radviz 展示投影结构，不等于原始高维空间的真实距离。
- **流与关系分离**：和弦图强调实体间关系，桑基图强调有方向的流量和阶段变化。

## Key Concepts
- **等值线图**：连接二维位置上相同数值的点。
- **矢量场**：用箭头方向与长度表示两个分量。
- **气泡图**：在散点位置之外用面积或颜色编码变量。
- **三元相图**：表示三个总和固定的组分比例。
- **3D 图**：使用第三个空间轴，但静态投影存在遮挡和透视问题。
- **平行坐标图**：每个变量是一条平行轴，每个样本是一条跨轴折线。
- **Radviz**：把变量作为圆周锚点，将样本投影到圆内。
- **PCA 图**：得分表示样本位置，载荷表示变量方向与贡献。
- **和弦图**：展示类别间连接强度。
- **桑基图**：用带宽展示从源到目标的流量。

## Mental Models
- **Use 2D unless 3D is necessary**：静态 3D 不是多变量图的默认答案。
- **Area is not radius**：气泡数值应映射到面积，不能直接映射半径。
- **Normalize before parallel coordinates**：不同量纲必须先标准化。
- **Order axes to reveal structure**：平行坐标轴顺序决定交叉数量和模式可见性。
- **Projection is a view, not the data**：降维图的分离需要结合解释方差和原始指标验证。

## Anti-patterns
- **一个图使用过多视觉通道**：颜色、大小、形状、透明度和线型同时出现会使图例失控。
- **气泡半径直接等于数值**：面积与数值平方相关，夸大差异。
- **无必要使用 3D 柱形图**：遮挡和透视使比较更困难。
- **平行坐标不缩放变量**：量纲差异掩盖真实模式。
- **PCA 不报告解释方差**：无法判断二维投影保留了多少信息。
- **Sankey 流量不守恒却不说明**：读者会错误理解带宽变化。

## Code Examples
```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-3, 3, 80)
y = np.linspace(-3, 3, 80)
X, Y = np.meshgrid(x, y)
Z = np.exp(-(X**2 + Y**2))
U, V = -Y, X

fig, ax = plt.subplots(figsize=(4.2, 3.4))
filled = ax.contourf(X, Y, Z, levels=12, cmap="viridis")
ax.contour(X, Y, Z, levels=12, colors="black", linewidths=0.35)
ax.quiver(X[::6, ::6], Y[::6, ::6], U[::6, ::6], V[::6, ::6], color="white")
fig.colorbar(filled, ax=ax, label="Intensity")
ax.set(xlabel="X", ylabel="Y", aspect="equal")
```
- **What it demonstrates**：位置表示空间坐标，颜色和等值线表示连续场，箭头表示方向变量。

## Reference Tables
| 数据结构 | 推荐图 | 关键检查 |
|---|---|---|
| 二维位置上的连续场 | 等值线/填色等值线 | levels、色条、插值 |
| 连续场加方向 | 等值线 + quiver/streamplot | 箭头缩放、采样密度 |
| x、y 加第三连续量 | 气泡图 | 面积映射、大小图例 |
| 三个和为常数的比例 | 三元相图 | 总和约束、刻度方向 |
| 真实三维几何 | 3D 散点/曲面 | 遮挡、视角、二维替代 |
| 多样本多指标 | 平行坐标 | 标准化、轴顺序、透明度 |
| 高维样本二维投影 | PCA/Radviz | 解释方差、缩放方法 |
| 类别间无方向关系 | 和弦图 | 连接过滤、节点排序 |
| 阶段性有方向流量 | 桑基图 | 流量守恒、带宽比例 |

## Worked Example
比较多个模型的五个性能指标时，先统一“越大越好/越小越好”的方向并标准化。查看各模型整体轮廓时使用平行坐标，并把相关指标相邻排列；解释样本分群时使用 PCA 得分图，在轴标签中标注解释方差，并用载荷箭头说明变量贡献。不要再把同一指标重复映射到点大小和颜色。

## Key Takeaways
1. 最重要的两个变量优先使用 x/y 位置。
2. 每个视觉通道都必须回答明确问题。
3. 3D 仅用于确有三维几何意义的场景。
4. 平行坐标与降维图必须处理量纲并说明限制。
5. 和弦图表关系，桑基图表有方向流量。
